# Username Search — демонстрация интерфейса

Прототип экранов бота для настройки поиска и просмотра примера проверки юзернеймов.

> **Демонстрационный макет, не работающий Telegram-бот.** Пример запускается локально и показывает только экраны и переходы. Он не подключается к Telegram и другим сервисам, не отправляет запросы, не хранит и не обрабатывает реальные пользовательские данные. Данные на экранах вымышлены. Оригинальные серверные компоненты и интеграции в репозиторий не включены.

## Что показано

- Меню нового поиска и параметров длины и количества.
- Демонстрационный экран процесса поиска.
- Пример результатов с вымышленными именами без проверки доступности.

## Пример стартового экрана

```text
Поиск юзернеймов
Макет интерфейса. Генерация и проверка имён в этой версии не выполняются.
1. Новый поиск
2. Профиль
3. Помощь
```

## Запуск

Нужен Python 3.10 или новее. Внешние библиотеки не требуются.

```bash
python demo.py
```

Выберите номер пункта меню. Чтобы выйти, введите `q`.

## Тесты

```bash
python -m unittest -v
```

## Структура

- `screens.json` — демонстрационные тексты, кнопки и переходы между экранами.
- `demo.py` — локальный просмотрщик экранов.
- `test_demo.py` — проверки структуры, навигации и обработки некорректного выбора.

Макет предназначен для демонстрации интерфейса проекта; он не предоставляет функций реального сервиса и не содержит конфигурации продакшена.
